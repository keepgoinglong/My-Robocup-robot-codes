# 8.0_16MHz

本目录由 8.0 复制，动作、视觉协议、越障、小碎步及其他算法保持不变。

启动调整：执行 `s` 到保持状态后，`g/t` 的实测姿态允许每个舵机最多偏离目标 50 计数，并从实测位置平滑开始下一帧；动作目标限位和运行中故障检查不变。

板载按键控制：

- KEY1/K1（PE1）：等同串口命令 `s`，进入站立姿态；行走中按下则沿用 `s` 的安全停止逻辑。
- KEY2/K2（PE0）：等同串口命令 `g`，从已完成的站立姿态开始行走并开启视觉控制。
- 两个按键均为板载 10 kΩ 上拉、按下低电平，软件使用 30 ms 消抖；一次按下只触发一次，松开后才能再次触发。

图形动作落脚规则：图形 1、2、5、6 统一等待右脚前摆并完成落地，在右脚位于前方且双脚都在地面的稳定帧 11 开始动作；图形 3、4 保持原动作时机。

SG90测试指令：调试串口输入小写 `j`，PA11/J1输出50 Hz PWM，SG90以约±50°每500 ms换向，持续3秒后回到中位；中位保持400 ms后关闭PWM。机器人行走或正在进入站姿时拒绝该测试，图形6继续复用同一套SG90驱动。

仅修改硬件时钟与串口引脚：

- 外部晶振：16 MHz，`HSE_VALUE=16000000U`，`PLLM=8`，系统时钟仍为 168 MHz。
- 视觉串口恢复 7.0：UART4，PC10=TX、PC11=RX，115200 8N1，中断收发。
- 调试控制台恢复 7.0：USART1，PA9=TX、PA10=RX，115200 8N1。
- 舵机串口保持 7.0：USART2，PD5=TX、PD6=RX，1 Mbps。
- HC-SR04 恢复 7.0：PA2=TRIG、PA3=ECHO。

Keil 工程仍使用 `MDK-ARM/HumanoidRobot_8_0.uvprojx`，以避免修改工程结构和源文件清单。

## 接线

### 16 MHz 版本（本目录）

- CanMV TX → 主板 PC11（UART4_RX）
- CanMV RX ← 主板 PC10（UART4_TX）
- CanMV GND ↔ 主板 GND
- 串口调试器 RX ← 主板 PA9（USART1_TX）
- 串口调试器 TX → 主板 PA10（USART1_RX）
- 串口调试器 GND ↔ 主板 GND
- 舵机适配器 RX ← 主板 PD5（USART2_TX）
- 舵机适配器 TX → 主板 PD6（USART2_RX）
- 舵机适配器 GND ↔ 主板 GND
- HC-SR04 TRIG ← 主板 PA2
- HC-SR04 ECHO → 主板 PA3
- HC-SR04 GND ↔ 主板 GND，VCC → 5V

### 8 MHz 版本（原 8.0）

- CanMV TX → 主板 PC7（USART6_RX）
- CanMV RX ← 主板 PC6（USART6_TX）
- CanMV GND ↔ 主板 GND
- 串口调试器 RX ← 主板 PA9（USART1_TX）
- 串口调试器 TX → 主板 PA10（USART1_RX）
- 串口调试器 GND ↔ 主板 GND
- 舵机适配器接线与上述 16 MHz 版本相同；原 8.0 的 HC-SR04 为 PA0/PA1。

注意：晶振频率是控制板硬件属性，不是外接模块。必须给对应晶振的控制板烧录相匹配的固件。本控制板原理图确认 PA3 为 FT 数字输入；该直连结论不能套用到其他 GPIO 或其他控制板。
